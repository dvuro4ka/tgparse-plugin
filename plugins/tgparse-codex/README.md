# TGParse

TGParse помогает исследовать публичные аккаунты соцсетей, сравнивать конкурентов,
получать метрики публикаций и расшифровки роликов. Можно скачать видео Instagram,
YouTube или TikTok, проверить тариф и баланс, а по явной просьбе — заказать
уникализацию видео. Уникализация расходует баланс версий; цена и доступность
проверяются перед заказом. Покупка проходит отдельно в боте или Mini App.

Плагин содержит общий навык `social-research` и удалённое подключение к
`https://tgparse-production.up.railway.app/mcp`. Локальный сервер не запускается.
Вход выполняется через OAuth с подтверждением в Telegram; ключи не нужны.

## Установка

Claude Code:

```text
/plugin marketplace add dvuro4ka/tgparse-plugin
/plugin install tgparse@tgparse
```

В claude.ai, Claude Desktop и Cowork: Customize → Plugins → Add → Add marketplace,
укажите `dvuro4ka/tgparse-plugin`, установите TGParse, затем подключите сервер
на вкладке Connectors и подтвердите вход в Telegram.

Codex 0.161.0:

```sh
codex plugin marketplace add dvuro4ka/tgparse-plugin
codex plugin add tgparse@tgparse
```

В ChatGPT: Plugins → + → Add custom MCP server, адрес сервера выше,
OAuth → Create as a plugin; подтвердите вход в Telegram. Этот способ подключает
инструменты сервера. Общий навык из репозитория устанавливается через локальный
маркетплейс в поддерживаемом ChatGPT desktop/Work; подробности — в
[README репозитория](https://github.com/dvuro4ka/tgparse-plugin#readme).

## Данные и приватность

На сервер TGParse отправляются выбранные аккаунты и ссылки, поисковые фразы,
параметры анализа, скачивания и заказов. OAuth связывает подключение с Telegram:
сервис использует идентификатор пользователя для доступа к его квотам, балансу
и заказам. Для расшифровки и обработки сервис получает соответствующее видео.
Результаты возвращаются в выбранный AI-клиент, а версии — также в Telegram.
Обработка может привлекать поставщиков данных и распознавания согласно политике
сервиса. Плагин не загружает файлы рабочего каталога сам по себе.

Ссылки на скачанные файлы и версии временные; не публикуйте их, они дают доступ
к файлу. Срок каждого результата берите из ответа сервера.
Правила хранения и обработки определяются политиками сервиса и AI-клиента.
