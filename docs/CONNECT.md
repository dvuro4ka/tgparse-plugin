# Текст для страницы /connect

Установите плагин TGParse: добавьте маркетплейс `dvuro4ka/tgparse-plugin` в Claude или Codex и выберите `tgparse@tgparse`.
В ChatGPT откройте Plugins → + → Add custom MCP server, укажите `https://tgparse-production.up.railway.app/mcp` и выберите Create as a plugin.
Подтвердите вход через Telegram — станут доступны исследование соцсетей, скачивание, баланс и уникализация по вашей просьбе.
